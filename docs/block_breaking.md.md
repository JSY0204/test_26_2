# INU 벽돌깨기 게임 서비스 제작 프롬프트

## 📌 기본 설정 및 메인 페이지 요구사항
- **웹페이지 타이틀**: `INU 벽돌깨기`
- **첫 화면 구성**:
  - 사용자 이름 입력란
  - 게임 시작 버튼
  - 제작자 정보 추가 (학과, 학번, 이름)
  - 우리대학 마스코트 횃불이 이미지 배치 (`test_26_2` 폴더 내 `mascot.jpg`)

## 🧱 벽돌 및 게임 구성
- **벽돌 기본 구성**: 5행 × 8열 (총 40개)
- **색상 구성**: 연한 빨강, 연한 주황, 연한 노랑색, 연한 파랑, 연한 녹색, 연한 보라색으로 랜덤 구성
- **테스트 규칙**: 연한 빨강 블록을 전체 블록의 30% 비율로 배치
- **게임 종료 조건 (테스트용 단축 규칙)**: 연한 빨강색 블록을 **3개 제거**하면 게임 완료 및 승리 처리

## 🕹️ 게임 플레이 및 조작
- **조작 방법**: PC 버전에서 좌우 방향키(`ArrowLeft`, `ArrowRight`)로만 패들이 자연스럽게 이동하도록 설정
- **생명 시스템**: 패들이 공을 놓쳐 화면 하단으로 떨어지면 생명 감소 (총 **3번**의 기회, 모두 소진 시 게임 오버)
- **카운트다운**: 게임이 처음 시작할 때만 `3, 2, 1` 준비 카운트다운 후 공의 움직임 시작

## 🎛️ 게임 컨트롤 버튼 (메인/게임 화면)
- **게임 중 제공 버튼**:
  - 일시정지 (게임을 중간에 멈출 수 있는 버튼)
  - 다시 시작 버튼 (클릭 시 이름을 작성하는 첫 화면으로 이동)
  - 게임 종료 버튼

## ⏱️ 시간 측정 및 미션 결과
- **시간 측정**: 게임 미션이 완료될 때까지 시간을 `분:초` 단위로 측정 (참고 게임과 동일한 표시 형식)
- **미션 성공**: 
  - 완료 시간을 측정하여 출력
  - 폭죽(Confetti/Fireworks) 효과 추가
- **미션 실패**: 
  - 시간을 측정하지 않고 **"게임 미션 실패"** 메시지 출력

## 🎵 사운드 및 효과음
- **배경 음악 (BGM)**: 게임 시작 시 `Hyper_Speed_Run.mp3` 파일을 배경 음악으로 재생 (볼륨이 너무 크지 않도록 적절히 조절)
- **효과음 (SFX)**: 공이 블록에 충돌할 때마다 타격 효과음 출력
